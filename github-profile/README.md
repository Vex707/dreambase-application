My application workbench contains synthetic-data demo editions, limitations, tests, case studies, and provenance notes. These examples are prepared with AI assistance and are separate from the original internal tools.

## How I approach a problem

Understand the workflow. Make the inputs explicit. Show what was rejected and why. Use model judgment where it helps, and deterministic checks where correctness can be expressed as a rule.
