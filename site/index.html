    Where AI ends and validation begins

    The existing vignette tool compares reference and floor images through a server-side Anthropic API proxy. This application demo adds a deterministic response-validation layer and replays fabricated output. A valid response shape cannot prove the visual judgment is correct. Real image evaluation, model accuracy, authenticated deployment, and live provider behavior remain separate tests.
