What I’m testing

SQL execution only establishes that a query can run. I compare its contributing records and total with an independent reference, then apply the grain, scope, amount, and freshness rules. Every failed check blocks acceptance.

Where this stops

This is a small SQLite work sample, not Dreambase’s DuckDB stack or a production agent. Browser checks are not authorization. The receipt is inspectable JSON, not a signed audit log. These fixtures cannot establish model accuracy or prove every query correct.
